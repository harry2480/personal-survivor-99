## 4. 実機で見るときの観点

### 4.1 操作（#3 #4 #5）

- 押してから動くまでが遅くないか（DAS / ARR の体感）
- 長押しの移動が速すぎ・遅すぎないか
- 回転が引っかからないか（Wall Kick）
- Controller と Keyboard で差がないか

### 4.2 表示（#28 の体感を含む）

- Main Board が見やすいか（[テストガイドライン.md](テストガイドライン.md) の UI 視認性チェック）
- 98 面の Opponent Grid を出しても重くならないか
- Debug Overlay の FPS が 60 を下回らないか

### 4.3 安定性（#27 #30）

- 10 試合で Crash・停止がないか
- Restart / Quit to Menu を繰り返しても崩れないか
- 数十分の連続プレイでメモリが増え続けないか（Debug Overlay の Memory）
