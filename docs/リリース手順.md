# Release 手順

macOS 向けに配布するまでの手順（Issue #58）。要件定義 §123 CI/CD / §124 macOS Build /
§125 Code Signing / §127 配布形態 に対応する。

---

## 1. 配布物

| ファイル | 内容 |
|---|---|
| `Project99-<version>-macos.zip` | `Project99.app` を詰めたもの（universal。Apple Silicon で動く） |
| `Project99-<version>-macos.zip.sha256` | SHA-256 |

`.dmg` と App Store 配布は対象外（要件定義 §127）。

---

## 2. 出す前に

1. [リリース前検証チェックリスト.md](リリース前検証チェックリスト.md) の「未実施」が無いこと
2. `main` の CI が緑であること
3. バージョンを上げること（下記 3.）

---

## 3. バージョンの上げ方

バージョンの出どころは **`project.godot` の `config/version`** の 1 箇所。

```ini
[application]
config/version="0.1.0"
```

`export_presets.cfg` の `application/short_version` と `application/version` も同じ値に合わせる
（`.app` の Info.plist に入る値）。

```sh
# 例: 0.2.0 にする
sed -i '' 's/config\/version="0.1.0"/config\/version="0.2.0"/' project.godot
sed -i '' 's/application\/short_version="0.1.0"/application\/short_version="0.2.0"/' export_presets.cfg
sed -i '' 's/application\/version="0.1.0"/application\/version="0.2.0"/' export_presets.cfg
```

変更は PR にして `main` へ入れる（`main` への直接 push は禁止。要件定義 §120）。

---

## 4. 手元で作る

```sh
scripts/package-macos.sh
```

やっていること。

```text
Export Templates の用意 → import → Export（Project99.app）→ zip に詰める → SHA-256
```

出力先は `dist/`（`.gitignore` 済み）。実測（0.1.0 / Apple Silicon で確認）。

```text
Project99.app                      … universal（x86_64 + arm64）
Project99-0.1.0-macos.zip          … 約 58 MB（展開後 171 MB）
Project99-0.1.0-macos.zip.sha256   … SHA-256
```

```text
dist/Project99.app
dist/Project99-0.1.0-macos.zip
dist/Project99-0.1.0-macos.zip.sha256
```

Export Templates が無い場合は `scripts/install-export-templates.sh` が入れる。

---

## 5. Release を出す

Tag を押すと GitHub Actions（`.github/workflows/release.yml`）が動く。

```sh
git tag v0.2.0
git push origin v0.2.0
```

ワークフローの中身。

```text
Godot セットアップ → Export Templates（キャッシュ）→ scripts/package-macos.sh
→ 成果物を Artifact に保存 → GitHub Release を作成（zip + sha256 を添付）
```

Tag 以外（手動実行）では Release を作らず、成果物の確認までで止まる。

---

## 6. 出したあとの確認

**配布物そのもので確認する**（ビルド環境で動いても、配布物で動くとは限らない）。

1. Release ページから zip をダウンロードする
2. チェックサムを照合する

   ```sh
   shasum -a 256 -c Project99-0.2.0-macos.zip.sha256
   ```

3. 展開して `Project99.app` を開く
4. [リリース前検証チェックリスト.md](リリース前検証チェックリスト.md) の実機項目を確認する

---

## 7. 署名していないことについて

現時点では Code Signing と Notarization を行っていない（要件定義 §125 で未決定）。
そのため、ダウンロードした `.app` は Gatekeeper に止められる。

初回は **右クリック →「開く」** で起動する。

署名するかどうかを決めたら、以下を足して手順を更新する。

- Apple Developer ID（`codesign/identity` / `codesign/apple_team_id`）
- Notarization（`notarization/*`）
- 署名鍵を GitHub Secrets に置く（リポジトリ設定は管理者作業。[リポジトリ設定手順.md](リポジトリ設定手順.md)）

---

## 8. うまくいかないとき

| 症状 | 見るところ |
|---|---|
| Export でエラーが出る | Export Templates のバージョンが `.godot-version` と合っているか |
| `.app` が起動しない | 未署名のため Gatekeeper に止められていないか（7.） |
| zip を展開すると壊れている | `ditto` ではなく `zip` で詰めていないか（symlink が壊れる） |
| Release が作られない | Tag から流したか（手動実行では作らない） |
