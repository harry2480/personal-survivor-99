# 2. プロジェクト概要

Nintendo Switchの「TETRIS 99」に近い、

「多数のプレイヤーが同時に落ちものパズルを行い、ライン消去による攻撃を送り合い、最後の1人になるまで戦う」

というゲーム体験をmacOS上で実現する。

初期バージョンではオンライン通信を使用せず、以下の99人戦を実装する。

```text
Human Player × 1
CPU Player × 98
= 99 Players
```

基本的な利用フローは以下とする。

```text
Macでアプリを起動
↓
Nintendo Switch Proコントローラーを接続
↓
99人戦を開始
↓
CPU 98人と対戦
↓
最後の1人になるまでプレイ
↓
順位・KO数等を確認
↓
即再戦
```

---

# 3. プロジェクト目標

本プロジェクトの主要目標は以下とする。

1. macOS上で単独アプリとして動作する
2. Apple Silicon Macを主要対象とする
3. Nintendo Switch Proコントローラーで快適に操作できる
4. キーボードでもプレイできる
5. 現代的な落ちものパズルとして高い操作レスポンスを実現する
6. 1 Human + 98 CPUによる99人バトルを成立させる
7. Target、Attack、Garbage、KO、Attack Multiplier等を実装する
8. CPU難易度を一般的な最高難易度以上まで自由に引き上げられる
9. Apple Silicon Macで安定して60 FPS以上を維持する
10. インターネット接続なしで完全に遊べる
11. 将来のWindows・Linux・LAN・Online対応を妨げない設計とする
12. Game Logic、UI、Input、Audioを疎結合に保つ

---

# 4. 非目標

MVPでは以下を対象外とする。

* 既存ゲームの内部仕様の完全コピー
* Nintendo Switchとの通信
* Nintendo Switch Onlineとの通信
* Nintendo公式サービスとの通信
* Nintendo Account連携
* 公式プレイヤーとのクロスプレイ
* 99人オンライン対戦
* Matchmaking
* Friend Match
* Global Ranking
* Cloud Save
* Anti-cheat
* Dedicated Server

本プロジェクトは独立したオフラインゲームとして構築する。

# 8. 実装言語

```text
Typed GDScript
```

を主言語とする。

原則:

* 型注釈を使用

# 58. CPUシステム基本方針

CPUは固定難易度だけではなく、ユーザーが非常に広い範囲で強さを変更できるものとする。

目的は、

「最高難易度でも簡単」

という状態を避け、プレイヤーが上達しても十分な挑戦を提供できること。

# 75. Survivor Scaling

原則として試合途中にCPUを不自然に強化しない。

以下を目指す。

```text
序盤
弱いCPU + 強いCPU

↓

弱いCPUが脱落

↓

終盤
強いCPUが自然に残る
```

これにより終盤難易度が自然に上昇する。

# 140. 主要リスク

## CPU負荷

Extreme / Machine CPUを98体動作させるとSearch負荷が高くなる。

対策:

* Detailed / Lightweight Hybrid
* Search制限
* Update Scheduling
* Cache
* Multithreading
* GDExtension

---

## CPU難易度と不公平感

強さを単純にPPSだけで上げると理不尽になりやすい。

対策:

* Thinking Quality
* Reaction
* Speed
* Mistake
* Technique

を分離する。

---

## UI情報量

98盤面によりMain Boardが見づらくなる。

対策:

* Main Board最優先
* Opponent簡略化
* Highlight
* 不要情報を減らす

---

## Controller差異

macOS / Godot / Bluetooth環境でMapping差異が発生する可能性。

対策:

* Input Action化
* Device Detection
* Remapping
* 実機Test

---

## Rule Fidelity

DAS / ARR / Lock Delay等の微差が操作感へ大きく影響する。

対策:

* Parameter化
* 実プレイ調整
* Core Logic分離

「Macでアプリを起動し、Nintendo Switch Proコントローラーを使って、インターネット接続なしでいつでも99人バトルロイヤル型落ちものパズルを快適に遊べること」

とする。

特にCPU対戦については、

「用意された最高難易度では物足りなくなったら終わり」

という構造にせず、

```text
Normal
↓
Hard
↓
Very Hard
↓
Extreme
↓
Strength 100+
↓
Strength 150+
↓
Machine
```

のように、プレイヤーの成長に合わせてCPU強度を継続的に引き上げられることを重要要件とする。

ゲーム全体としては、

* 高レスポンスな落ちものパズル操作
* 99人同時Battle
* Targeting
* Garbage攻撃
* KO
* 終盤の緊張感
* 自由度の高いCPU難易度
* 安定したmacOS動作

を独自実装として成立させることを最終目的とする。
