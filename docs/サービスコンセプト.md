# Project 99 - サービスコンセプト

> 開発時仮称: **Project 99**（公開名称は別途決定する）

## 概要

Project 99 は、**macOS 上で 1 人の人間プレイヤーと 98 体の CPU が同時に落ちものパズルを行い、
ライン消去による攻撃を送り合って最後の 1 人を決める**バトルロイヤル型パズルゲームです。

インターネット接続を必要とせず、Mac を起動して Nintendo Switch Pro コントローラーを繋げば、
いつでも 99 人戦を遊べることを目指します。

```text
Human Player × 1
CPU Player × 98
= 99 Players
```

## 基本フロー

```text
Macでアプリを起動
↓
Nintendo Switch Proコントローラーを接続
↓
99人戦を開始
↓
CPU 98人と対戦
↓
最後の1人になるまでプレイ
↓
順位・KO数等を確認
↓
即再戦
```

## コンセプト

### 1. 高レスポンスな落ちものパズル操作

**目的**: 現代的な落ちものパズルとして違和感のない操作感を実現する

**要素**:
- DAS / ARR / Lock Delay / Soft Drop Speed をユーザー設定可能にする
- Gravity は FPS 非依存の時間ベース処理とし、Render FPS で挙動を変えない
- Human Input を常に最優先し、CPU 98 体の思考負荷で操作を遅延させない
- SRS 系 Rotation、Wall Kick、7-Bag、Hold、Next、Ghost を実装する

### 2. 99 人同時バトル

**目的**: 大人数バトルロイヤル特有の攻防と終盤の緊張感を成立させる

**要素**:
- Attack / Garbage / Garbage Cancellation による攻防
- Target Mode（Random / KO / Badge / Counter）と Manual Target
- KO、Ranking、Attack Multiplier
- 残存人数（99 / 50 / 20 / 10 / 5 / 2）に応じた BGM・演出・UI の段階変化

### 3. 上限のない CPU 難易度

**目的**: 「用意された最高難易度では物足りなくなったら終わり」という構造を避ける

**要素**:
- CPU は 0〜100 の連続値 Strength を持ち、内部的に 100 を絶対上限としない（120 / 150 / 200 も設計上許容）
- Strength は Placement Quality / Search Depth / Reaction Time / PPS / Misdrop Rate 等の複合値として扱う
- Preset（Easy / Normal / Hard / Very Hard / Extreme / Custom）と Advanced Settings の 2 段階 UI
- 「強いが人間的な CPU」と「純粋に最強の Machine CPU」を分離して設定できる
- 99 体に Strength 分布（Average / Min / Max / Variance）を与え、終盤に強い CPU が自然に残る（Survivor Scaling）

```text
Normal → Hard → Very Hard → Extreme → Strength 100+ → Strength 150+ → Machine
```

### 4. オフラインで完結する macOS アプリ

**目的**: ログイン・通信・外部サービスに依存せず、単体で遊べる

**要素**:
- Apple Silicon Mac を主要対象とした `.app` として配布
- Nintendo Switch Pro コントローラー（Bluetooth）とキーボードの両対応
- Settings / Input Bindings / CPU Settings / Statistics をローカル保存
- 起動時にログインやネット接続を要求しない

---

## 期待される体験

1. **即座に遊べる** - 起動からプレイ開始まで待たされず、終了後は即再戦できる
2. **操作が素直** - 入力遅延がなく、パラメータを自分の好みに合わせられる
3. **終盤に緊張感がある** - 残存人数の減少に合わせて難度と演出が自然に上がる
4. **飽きない** - プレイヤーが上達しても CPU 強度を上げ続けられる

---

## 非目標（MVP 対象外）

- 既存ゲームの内部仕様の完全コピー
- Nintendo Switch / Nintendo Switch Online / Nintendo 公式サービスとの通信、Nintendo Account 連携
- 公式プレイヤーとのクロスプレイ
- 99 人オンライン対戦、Matchmaking、Friend Match、Global Ranking
- Cloud Save、Anti-cheat、Dedicated Server

本プロジェクトは**独立したオフラインゲーム**として構築する。

## 知的財産上の方針

一般公開する場合、既存ブランド・素材をそのまま複製しない。以下の使用を避ける。

既存ゲーム名称 / 既存ロゴ / Nintendo ロゴ / 公式 BGM / 公式 SE / 公式背景 /
公式 UI Asset / 公式画像 / 公式 Icon / 公式素材の直接コピー

公開タイトル、UI、Graphic、Audio は独自のものとし、コード内部も既存ブランドへ不要に依存させない。

## 最終ゴール

> 「Mac でアプリを起動し、Nintendo Switch Pro コントローラーを使って、
> インターネット接続なしでいつでも 99 人バトルロイヤル型落ちものパズルを快適に遊べること」

加えて、プレイヤーの成長に合わせて CPU 強度を継続的に引き上げられることを重要要件とする。
