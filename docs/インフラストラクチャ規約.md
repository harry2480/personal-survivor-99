# Project 99 ビルド・CI/CD・配布規約

Godot Engine 4.x + GitHub Actions による開発基盤の構成と規約。
本プロジェクトにサーバー・データベース・ホスティングは存在しない。対象は**ローカル開発環境、CI、macOS ビルド、配布**である。

## 開発環境

```text
macOS
Godot 4（Editor）
Git
GitHub
VS Code
```

AI 支援候補: Claude Code / Codex CLI

## CI/CD

GitHub Actions を使用する。

| トリガー | 実行内容 |
|---|---|
| Pull Request / push | Static Check / Import・起動検証 / Headless テスト / macOS Export Validation |
| Release | Production Build / Package / Checksum / GitHub Release（Phase 10） |

集約 job は `CI ステータス確認`（job ID `ci-status`）。branch protection ではこれだけを
required check に指定する。

### 実行環境

- Godot は**固定バージョンのバイナリを取得して使用**する。Runner に入っている任意のバージョンに依存しない
- テストは `--headless` で実行できることを必須要件とする（[テストガイドライン.md](テストガイドライン.md)）
- 外部サービス・ネットワーク・シークレットに依存するジョブを CI の必須チェックに入れない

CI とローカルは同じスクリプトを実行する。Godot の取得と SHA-512 検証は
composite action `.github/actions/setup-godot` に集約している。

```sh
scripts/static-check.sh   # Lint / フォーマット / 命名規約 / 依存方向
scripts/verify-godot.sh   # import + 起動検証
scripts/run-tests.sh      # 自動テスト（GUT）
scripts/export-macos.sh   # macOS Export Validation
```

## macOS ビルド

Godot Export を使用する。

| 項目 | 内容 |
|---|---|
| 対象 | macOS / Apple Silicon（M1 以降） |
| 成果物 | `GameName.app` |
| 配布形式 | `.zip`（将来的に `.dmg`） |
| Export Preset | `export_presets.cfg` の `macOS`。CI とローカルで同一のプリセットを使う |

- MVP では macOS 以外の動作保証を行わない。Intel Mac / Windows 11 / Linux は将来候補
- Export Preset や出力パスをローカル環境に依存させない

### Code Signing

- 個人利用では必須としない
- 一般配布時は Apple Developer ID / Code Signing / Hardened Runtime / Notarization を導入する
- 署名に用いる証明書・パスワードは GitHub Secrets で管理し、リポジトリへコミットしない

## アセット・権利管理

- BGM / SE / フォント / 画像は、独自制作物か**適切な利用許諾を確認したもの**のみをリポジトリへ追加する
- 出典とライセンスを記録し、再配布条件を満たすこと
- 既存ゲームの公式素材（ロゴ・BGM・SE・背景・UI Asset・Icon）を取り込まない
