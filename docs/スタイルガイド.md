# Project 99 スタイルガイド

Godot の Theme / UI 表現に関するプロジェクト共通のスタイルルール。
画面構成は [フロントエンドアーキテクチャ.md](フロントエンドアーキテクチャ.md)、実装規約は [フロントエンド規約.md](フロントエンド規約.md) を参照。

---

## 1. 色・フォントは Theme に集約する

### ルール

- 色、フォント、フォントサイズ、余白は **Theme リソース（`assets/themes/`）に定義**する
- Scene / スクリプト内で `Color(0.1, 0.2, 0.3)` のような値を直接書かない
- Piece 色、Garbage 色、Danger 色などゲーム上の意味を持つ色は**名前付き定数または Theme の色**として定義する

### 理由

99 人戦では同じ色表現が Player Board・Opponent Grid・HUD の 3 箇所に同時に現れる。
値を散らすと配色変更や Color Blind Theme 追加のたびに全画面を探すことになるため。

### 具体例

```gdscript
# NG
panel.modulate = Color(0.9, 0.2, 0.2)

# OK
panel.modulate = get_theme_color("danger", "BoardView")
```

---

## 2. 色だけに情報を持たせない

### ルール

- **Target 表示**と **Danger 表示**は、色に加えて枠線・アイコン・形状・点滅のいずれかを併用する
- Alive / Dead の区別も、彩度差だけでなく表示要素（グレーアウト + マーク）で区別する
- 「赤いから危険」「光っているから狙われている」だけで成立する UI を作らない

### 理由

色覚特性や輝度設定の違いで情報が失われるため。要件定義 §128 のアクセシビリティ要件でもある。

---

## 3. Magic Number を書かない

### ルール

- 座標、サイズ、間隔、アニメーション時間を直接数値で埋め込まない
- レイアウト定数は Theme の constant、ゲーム挙動に関わる値は `config/` のバランスデータに置く
- セルサイズや盤面寸法（表示 `10 × 20` / 内部 `10 × 40`）は定数として一箇所で定義する

### 具体例

```gdscript
# NG
piece_sprite.position = Vector2(x * 32, y * 32)

# OK
piece_sprite.position = Vector2(x, y) * BoardMetrics.CELL_SIZE
```

---

## 4. レイアウトは Anchor / Container で組む

### ルール

- 絶対座標でのレイアウトを避け、Control の Anchor と Container（`VBoxContainer`, `GridContainer` 等）を使う
- 以下の解像度でレイアウト破綻がないことを確認する。Retina（`content_scale`）を考慮する

```text
1280 × 800
1440 × 900
1920 × 1200
2560 × 1600
```

- Fullscreen / Window 切替、ウィンドウリサイズでレイアウトが崩れないこと

### 理由

主対象は Mac の 16:10 だが、ウィンドウサイズは実行中に変わる。固定座標は必ず破綻する。

---

## 5. Main Board の視認性を最優先する

### ルール

- 新しい情報を画面へ追加するときは、[フロントエンドアーキテクチャ.md](フロントエンドアーキテクチャ.md) の UI 優先順位に従って配置と面積を決める
- Opponent Grid の演出・装飾で Player Board のコントラストを下げない
- 全画面エフェクト（フラッシュ、シェイク、パーティクル）は Player Board を覆い隠さない強度に抑える

---

## 6. 演出は削減可能にする

### ルール

- Screen Shake は設定で軽減できるようにする
- 装飾エフェクトは `EffectLayer` に集約し、負荷時・設定時に一括で抑制できるようにする
- 演出が停止してもゲーム進行の情報（Rank / Incoming / Target）が読み取れる状態を保つ

---

## 7. 表記ルール

- UI 上の Clear 名称（Single / Double / Triple / Quad 等）は**独自名称に差し替え可能**にする。
  文言をスクリプトへ直書きせず、表示用のテーブルを経由する
- 既存ブランドの名称・ロゴ・公式素材を UI に使用しない（[サービスコンセプト.md](サービスコンセプト.md) の知的財産方針）
- 数値表示は桁揃えし、残存人数・KO 数・Rank はフレーム間でガタつかない固定幅で描画する
